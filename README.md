# 🦆 Tortuga Duck

Discord-бот для своих: бармен, диджей и швейцар в одном клюве.

**Установка с нуля — в [INSTALL.md](INSTALL.md).**

## Что умеет

**🎵 Музыка** (Lavalink)
- `/play` — поиск по SoundCloud, ссылки SoundCloud/Bandcamp, ссылки Spotify (ищутся на SoundCloud), свой MP3 файлом, интернет-радио по прямой ссылке
- Плейлисты и альбомы целиком
- Плеер в чате с прогресс-баром и кнопками ⏯ ⏭ ⏹ 🔀 🔁 🔉 🔊 📜
- Громкость по умолчанию 50%, режим «перемешано» / «по порядку», повтор трека/очереди
- Управлять можно только из того голосового канала, где сидит бот
- DJ-режим (вкл/выкл): управляют только DJ и админы, свой трек можно пропустить самому
- Бот уходит, если остался в канале один
- YouTube намеренно отключён

**🔊 Приватные каналы**
- Join to Create: зашёл в лобби → получил свой голосовой канал
- Панель кнопок: название, лимит, закрыть/открыть, скрыть/показать, пустить, выгнать, передать владение, забрать
- Пустой канал удаляется через 15 минут

**👋 Приветствия и роли**
- Карточка новичка: аватар, ник, случайная утка из `assets/ducks/`, случайная фраза из `config/welcome.json`
- Базовая роль выдаётся всем автоматически
- Чеклист ролей (`/roles` и панель с кнопкой), роли создаются сами по названию из `config/roles.json`

**📰 Новости**
- Игры, кино и сериалы, аниме (Telegram-канал @animolll через RSSHub), халява (GamerPower) — каждая категория в свой канал
- Без дублей, без флуда на первом запуске, не больше N постов за проход

## Стек
TypeScript + discord.js, Lavalink 4 + LavaSrc, SQLite (встроенный в Node), Docker Compose.

## Структура
```
src/index.ts              — запуск, регистрация команд, маршрутизация
src/modules/music.ts      — музыка и плеер
src/modules/privateVoice.ts — приватные голосовые
src/modules/welcome.ts    — приветствия и базовая роль
src/modules/roles.ts      — чеклист ролей
src/modules/news.ts       — RSS и раздачи
src/modules/setup.ts      — /setup для админов
config/                   — роли, фразы, ленты (правятся без пересборки)
assets/                   — картинки уток и фоны
lavalink/application.yml  — настройки аудиосервера
```
