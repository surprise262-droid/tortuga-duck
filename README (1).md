# Картинки для приветствий

- `ducks/` — картинки утки (PNG с прозрачным фоном лучше всего, можно JPG/WEBP/GIF).
  Для каждого новичка бот берёт случайную. GIF на карточке будет без анимации.
- `welcome/` — фоны карточки (желательно 1100×420 или больше). Если папка пустая — будет янтарный градиент.
- `fonts/title.ttf` — свой шрифт (необязательно). Нужна поддержка кириллицы.

Новые картинки подхватываются сразу, перезапуск бота не нужен.
